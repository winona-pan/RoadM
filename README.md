# 我的書房

家裡紙本書和讀墨、Kobo、Kindle 電子書的館藏。用來避免重複買書，也督促自己把買了的書讀完。

## 第一次打開：設定與教學
第一次打開會有幾步設定：
- 勾選你用哪些格式（紙本、讀墨、Kobo、Kindle、其他電子書）。之後新增書時只會出現這些選項。
- 寫下紙本書放在哪些書櫃。
- 設定今年想讀完幾本。
- 最後一頁是教學：怎麼掃條碼、加一整套、貼上電子書清單、在書店查有沒有買過。

這些之後都可以在「設定 → 使用教學與初始設定」重新打開、修改。

## 書房
- **封面畫面**：書櫃可以切換「封面牆」（一排三本）和「清單」兩種排法。沒有封面的書會自動做一個有書名、作者的封面。
- **繼續閱讀**：首頁最上面一排大封面，放閱讀中的書和放最久的未讀書。
- **類別**：用卡片顯示各類別有幾本，點一下就只看那一類。
- **拍封面認書**：按搜尋框旁的相機，把封面對準框框拍，會自動裁成這本書的封面，並在手機上讀出封面上的字，自動填入書名和作者，再用書名去線上查。讀錯的話，點一下其他讀到的字就能換。文字辨識在手機上進行，照片不會上傳；第一次使用要下載約 8MB 的辨識資料。iPhone 也可以在書名欄位選「掃描文字」。
- **AI 辨識（選用）**：到「設定」貼上 Anthropic API 金鑰後，拍封面或版權頁時由 AI（Claude）判斷書名、作者、出版社、ISBN、系列和第幾集，中文、日文、英文都看得懂。金鑰只存在自己手機的瀏覽器；照片會傳給 Anthropic 辨識，每張約台幣幾毛錢。沒開啟時用手機內建辨識（繁中、日文、英文）。
- **拍版權頁**：封面讀不到的話（藝術字、直排書名），封面照片會留著當封面，再按「拍版權頁」拍書最前面或最後面寫著書名、作者、出版社、ISBN 的那頁，會自動填好；有 ISBN 的話，也會用 ISBN 再線上查一次。
- **書的詳細頁**：點封面打開，可以直接切換狀態、換封面、記借給誰。
- **我有這本嗎？**：輸入書名、作者或 ISBN，或直接掃書背的條碼。已經有的會用橘色提醒；沒有的會顯示「可以放心買」。適合在書店用。
- **系列一起放**：漫畫和套書（例如哈利波特）會收成一張卡片，用小方塊顯示每一集：實心是讀完，橘色是閱讀中，空心是未讀，虛線是沒有這集。按「＋」可以加下一集。
- **格式**：可以標紙本、讀墨、Kobo、Kindle 或其他電子書，同一本書可以勾好幾種。
- **狀態**：未讀、閱讀中、讀完、放棄。
- **自動分類**：依書名、作者和線上書目資料分成漫畫、推理懸疑、文學小說、心理勵志等類別，分錯可以自己改。
- **放在哪**：記下紙本書放在哪個書櫃。
- **借出**：可以記下借給誰、哪一天借的。

## 讀書計畫
- 顯示有幾本書已經買了還沒讀，以及一週讀一本要讀多久。
- **今天讀哪一本？**：從未讀的書裡隨機挑一本，放越久的越容易被挑到。
- 列出閱讀中的書，讀完時按「讀完了」。
- 年度目標進度，以及今年買了幾本、讀完幾本的對照。
- 列出放最久的未讀書和借出中的書。

## 新增書的方法
- **一本**：搜尋書名、輸入 ISBN 或掃條碼，自動帶入作者和封面（資料來源：Google Books、Apple Books 台灣、Open Library）。
- **一整套**：例如「鬼滅之刃 1–23 集，已讀到第 5 集」，一次建立好；已經有的集數會跳過。
- **貼上清單**：從讀墨、Kobo、Kindle 的書櫃複製書名，一行一本貼上。重複的會跳過；書名結尾有數字的會自動歸成系列。

## 使用方式
整個 app 就是一個 `index.html`。開啟 GitHub Pages 後，在 iPhone Safari 打開 `https://winona-pan.github.io/RoadM/`，再按「分享 → 加入主畫面」。條碼掃描需要允許相機權限。

## 資料與備份
資料只存在這台裝置的瀏覽器（localStorage），不會上傳到任何地方。換手機或清除 Safari 資料前，請到「設定 → 匯出備份」，之後再「從備份還原」。也可以匯出成 CSV，用試算表打開。
舊的「旋律日記」書櫃裡的書，可以用書房頁面上的提示，或「設定」裡的按鈕搬過來。

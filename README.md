# 我的書房

家裡紙本書和讀墨、Kobo、Kindle 電子書的館藏。用來避免重複買書，也督促自己把買了的書讀完。

## 書房
- **我有這本嗎？**：輸入書名、作者或 ISBN，或直接掃書背的條碼。已經有的會用橘色提醒；沒有的會顯示「可以放心買」。適合在書店用。
- **系列一起放**：漫畫和套書（例如哈利波特）會收成一張卡片，用小方塊顯示每一集：實心是讀完，橘色是閱讀中，空心是未讀，虛線是沒有這集。按「＋」可以加下一集。
- **格式**：可以標紙本、讀墨、Kobo、Kindle 或其他電子書，同一本書可以勾好幾種。
- **狀態**：未讀、閱讀中、讀完、放棄。
- **自動分類**：依書名、作者和線上書目資料分成漫畫、推理懸疑、文學小說、心理勵志等類別，分錯可以自己改。
- **放在哪**：記下紙本書放在哪個書櫃。
- **借出**：可以記下借給誰、哪一天借的。

## 讀書計畫
- 顯示有幾本書已經買了還沒讀，以及一週讀一本要讀多久。
- **今天讀哪一本？**：從未讀的書裡隨機挑一本，放越久的越容易被挑到。
- 列出閱讀中的書，讀完時按「讀完了」。
- 年度目標進度，以及今年買了幾本、讀完幾本的對照。
- 列出放最久的未讀書和借出中的書。

## 新增書的方法
- **一本**：搜尋書名、輸入 ISBN 或掃條碼，自動帶入作者和封面（資料來源：Google Books、Apple Books 台灣、Open Library）。
- **一整套**：例如「鬼滅之刃 1–23 集，已讀到第 5 集」，一次建立好；已經有的集數會跳過。
- **貼上清單**：從讀墨、Kobo、Kindle 的書櫃複製書名，一行一本貼上。重複的會跳過；書名結尾有數字的會自動歸成系列。

## 使用方式
整個 app 就是一個 `index.html`。開啟 GitHub Pages 後，在 iPhone Safari 打開 `https://winona-pan.github.io/RoadM/`，再按「分享 → 加入主畫面」。條碼掃描需要允許相機權限。

## 資料與備份
資料只存在這台裝置的瀏覽器（localStorage），不會上傳到任何地方。換手機或清除 Safari 資料前，請到「設定 → 匯出備份」，之後再「從備份還原」。也可以匯出成 CSV，用試算表打開。
舊的「旋律日記」書櫃裡的書，可以用書房頁面上的提示，或「設定」裡的按鈕搬過來。
